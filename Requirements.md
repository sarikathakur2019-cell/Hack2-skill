# SakhiAI – AI Mental Wellness Assistant

## Problem Statement
Many people in India struggle with mental stress but hesitate to seek help due to stigma, language barriers, and cost.

## Proposed Solution
SakhiAI is an AI-powered chatbot that provides emotional support in Hindi and English.

## Features
- Emotion detection using AI
- Support in Hindi & English
- Breathing exercise suggestions
- Motivational messages
- Emergency helpline guidance
- WhatsApp/Web integration

## Target Users
- Students
- Working professionals
- Housewives
- Rural population

## Technology Stack
- OpenAI API (for emotion detection)
- Python / Node.js
- WhatsApp API / Web Interface
- Twilio (for SMS)

## Future Scope
- Add regional languages (Punjabi, Tamil, etc.)
- Voice-based conversation
- Mood tracking dashboard
